### [commit-rewriter 0.1：清理 AI 代理提交信息的本地 Web 工具](https://simonwillison.net/2026/Sep/14/commit-rewriter/) ⭐️ 6.0/10

Simon Willison 发布了 commit-rewriter 0.1，一个可通过 uvx 运行的小型 Web 工具，用来编辑和重写仓库中的 commit message。它最初用于 Datasette 的安全版本发布，因为初始提交里混有编码代理留下的杂乱内容以及来自私有仓库的 issue ID 引用，不适合直接公开。使用方式是在仓库目录运行 \`uvx commit-rewriter path/to/repo\`（已在仓库目录时可省略路径）；提交编辑后，工具会基于当前仓库状态创建一个带时间戳的分支以便回退，并从第一个被编辑的提交一直重写到最新提交。界面可按 message、author 或 hash 搜索，支持只显示已编辑项，并能查看每个提交的完整格式化 diff。

rss · Simon Willison · 9月14日 00:28

**「为什么现在」** 编码代理参与提交后，公开仓库前清理 commit message 中的代理痕迹和私有引用，正成为一个具体的工程步骤；commit-rewriter 0.1 把这一步骤做成了可本地运行的工具。它是否会被广泛采用尚不可知，材料只展示作者在 Datasette 安全发布中的用法。

**「内容角度」** 可做角度：以“AI 代理写的 commit 不能直接发布”为起点，用 commit-rewriter 0.1 演示如何批量编辑 commit message、按需创建可回退的时间戳分支，并讨论在公开仓库前清理私有 issue 引用和代理痕迹的操作流程与风险边界。
