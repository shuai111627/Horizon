### [Shopify 把移动端从 React Native 迁回原生 Swift 与 Kotlin](https://simonwillison.net/2026/Sep/10/shopify-react-native/) ⭐️ 7.0/10

Shopify 工程博客宣布，其移动应用将从 React Native 迁回分别用 Swift 和 Kotlin 编写的原生代码库。文章回顾 2020 年转向 React Native 的三条理由——不重复构建同一功能、让开发者跨栈工作、少花时间追平功能差异——并表示“原生仍意味着在两个平台上构建和维护软件，这项成本并未消失”，改变的是代理现在能完成足够多的实现、翻译、测试和评审工作，使其不再是 2020 年那样的决定性因素。Shopify 是 react-native-skia、flash-list、restyle 三个 React Native 库的维护方：前两个正在寻找新的归属，restyle 因“用户基数小于我们其他库”将于 2026 年底归档。材料未提供基准测试、代理工具细节或可量化的生产力数据。

**「为什么现在值得注意」** 这是一家大型电商平台公开逆转其 2020 年 React Native 决策，并把 AI 编码代理明确列为成本计算改变的变量，而非把迁移影响写成既定结论。迁移的具体范围、时间表和实际生产力收益在材料中均未给出。

**「评论讨论」** Hacker News 评论中，一位自称 iOS 工程师的人对打破“共享代码库”论调表示认同；也有人认为跨 JS、C++ 和原生线程调试崩溃的成本高于维护两套代码库。分歧在于 AI 是否构成迁移使能条件：一位参与过中型 React Native 应用重写的评论者称其大部分工作发生在 2026 年 1 月之前且未使用 LLM，因此不认同“LLM 让原本过贵的迁移变得可行”的叙事；另一位则称用 Codex 在夜间完成了约 15–20 个界面的 iOS 与 Android 移植，之后几天做打磨。这些均为个人经验陈述，不构成结论。

### [trynix.dev：在浏览器里启动任意 Nix 包](https://simonwillison.net/2026/Sep/10/trynix/) ⭐️ 5.0/10

Simon Willison 介绍了 Farid Zakaria 的 trynix.dev：它用 qemu-wasm 在浏览器中通过 WebAssembly 运行一台 x86\_64 Linux 虚拟机，并能用过去 13 年间的任意 Nix 包启动该虚拟机。这些环境是 URL 可寻址的，例如打开 https://trynix.dev/?pkg=python3%403.6.2 并点击“Load”，就能进入运行 2017 年发布的 Python 3.6.2 的交互式 shell。作者还基于它做了 trynix-preview：一个 GitHub Action，在 pull request 上评论一条链接，让该 PR 的构建在浏览器中启动，宣称无需服务器。受影响的场景主要是开发者复现旧版本环境和审查构建。

rss · Simon Willison · 9月10日 23:44

**「为何此刻值得注意」** 材料给出的时间线是 Farid Zakaria 于 2026 年 9 月 4 日发布相关文章，9 月 9 日又发布了用启动方式审查 pull request 的做法，Simon Willison 随后在博客中转述，来源页面还标注了 Lobste.rs 的讨论入口。可以确认的是这两个新演示与新工具已经公开；“无需服务器、只需浏览器”是工具自身的描述，其对实际审查流程和生产环境的效用尚未在材料中得到验证。

**「可做角度」** 可做角度：以“浏览器里点一下链接，就跑起 2017 年的 Python 3.6.2”这个可亲自验证的演示为切口，说明 qemu-wasm 如何把 Nix 的可复现环境搬进网页，并顺势对比 trynix-preview 把 PR 构建变成一条可点击链接的思路；讲清这是演示与工作流实验，不把它当成已经验证的生产方案或性能结论。

### [NASA 卫星图像增强技巧被用于显现古代岩画](https://spinoff.nasa.gov/Manipulating_Satellite_Photos_Now_Reveals_Ancient_Images) ⭐️ 3.0/10

NASA 技术转移（spinoff）文章介绍了最初用于卫星照片的图像处理方法——去相关拉伸（decorrelation stretch）等——如今被用来增强影像、显现古代岩画。HN 帖子给出了该方法的原始 PDF 与 NASA 官网两条链接，讨论集中在遥感图像处理而非 AI 模型或产品。文章引述 Harman 的话称，在很多情况下人们并不真正清楚这些岩画被创作的原因。受影响的场景主要是遥感/GIS 学习者和图像处理爱好者，以及考古影像判读。

hackernews · gumby · 9月10日 15:29 · [社区讨论](https://news.ycombinator.com/item?id=49645437)

**「可做角度」** 可做角度：把“去相关拉伸/假彩色合成”当作一次可复现的经典遥感实验——按评论中给出的 GIMP LAB 分解步骤（分解到 LAB，对 A/B 色度通道做自动色阶并移动中间调，再重新合成）处理一张卫星影像，说明增强后哪些低对比度细节变得可见，同时明确这是图像处理技巧而非 AI 能力。
