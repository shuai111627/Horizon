### [web-edit 0.1a0](https://simonwillison.net/2026/Oct/12/web-edit/) ⭐️ 4.0/10

Simon Willison 发布了 web-edit 0.1a0，这是一个小型 Python Web 应用，提供在某个文件夹中浏览和编辑文件的 Web UI，发布页面标注为 alpha 版本。他说明起因是在手机上用 Codex Remote 做项目时，想编辑一个凭据文件，又不希望凭据经由 LLM 往返，于是让 Codex 和 GPT-6 Astra Extra High 写出这个应用；它设计为通过 Tailscale 运行，由智能体启动后，他可以直接从手机的 Tailscale 网络编辑文件。界面包含文件列表（名称、大小、修改时间、下载与删除）、刷新、上传文件、新建文件，以及上传队列等元素；小于 2 MB 的图片可内联显示，选中文本文件即可编辑。文本编辑使用 CodeMirror 6，作者提到原本想用 Monaco，但后者目前的移动端体验还不够好。

rss · Simon Willison · 10月12日 15:54

**「为什么现在值得注意」** 这条发布对应的是一个已经在发生的工作流变化：用手机远程指挥编码智能体时，如何让敏感凭据不进入模型上下文。作者给出的做法是把文件编辑放到 Tailscale 内网的本地 Web UI 里完成，而不是让模型代读代写。需要注意这仍是 0.1a0 的 alpha 版本，作者没有给出任何安全审计、适用范围或性能方面的结论。
